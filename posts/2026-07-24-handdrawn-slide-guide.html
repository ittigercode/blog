🎨 手绘幻灯片 Skill 实战全记录

2026-07-24 · 从踩坑到跑通的最全指南
handdrawn-slide-skill-pack 能把文章一键转成手绘风格幻灯片配图。本文记录从安装到跑通的全过程，包含 4 个关键难点的解决方案。

一、Skill 是什么

一个双技能包：

技能角色功能
turning-articles-into-handdrawn-decks编排层读文章 → 拆页面 → 定义每页 brief
generating-handdrawn-slide-images原子层根据 brief 生成一张手绘 PNG

两条生图路径：

  • Qwen 直连：脚本直接调 DashScope API，一条命令出图
  • Host-native 收口：外部工具画图 → 脚本校验清洗 → 交付

二、安装过程

2.1 安装技能

unzip handdrawn-slide-skill-pack-v1.2.0.zip
cp -r handdrawn-slide-skill-pack/generating-handdrawn-slide-images ~/.hermes/skills/
cp -r handdrawn-slide-skill-pack/turning-articles-into-handdrawn-decks ~/.hermes/skills/

2.2 安装依赖

pip install Pillow --break-system-packages
难点 1：PEP 668 限制。 Ubuntu 22.04+ 禁止全局 pip install。用 --break-system-packages 或创建 venv。

三、Qwen 路径：理想丰满，现实骨感

3.1 理论流程

export DASHSCOPE_API_KEY="***"
export DASHSCOPE_WORKSPACE_ID="***"
export DASHSCOPE_REGION="beijing"

python3 scripts/generate_image.py --preflight
python3 scripts/generate_image.py --request page.json --output page.png --dry-run
python3 scripts/generate_image.py --request page.json --output page.png

3.2 踩坑记录

难点 2：需要三个环境变量，缺一不可。
DASHSCOPE_API_KEY + DASHSCOPE_WORKSPACE_ID + DASHSCOPE_REGION。其他模型只需一个 Key，千问需要三个。
难点 3：Workspace ID 获取路径变更。
百炼新平台已移除 Workspace 概念。需在 bailian.console.aliyun.com 创建应用获取。即使拿到正确的 ID，仍然失败。
难点 4：qwen-image-2.0-pro 模型不兼容。
脚本内置了 Pro 模型，但 API 调用反复报 exit 8（内容审核拒绝）和 exit 12（内部错误）。切换到标准版 qwen-image-2.0 也不行——脚本强校验模型名，只认 Pro 和 Pro 日期快照。

3.3 结论

Qwen 直连路径在我（WSL + 百炼 Key）的环境下 无法跑通。核心矛盾：脚本锁定 Pro 模型，而 Pro 模型的 API 在当前环境下不兼容。

四、Host-native 路径：山重水复后的柳暗花明

4.1 核心思路

Qwen 直连不行，但 bl image generate 能正常画图。所以：

bl image generate → 生图 → skill --adopt 收口 → 校验 → 交付

4.2 完整流程

Step 1：创建页面描述

cat > /tmp/page.json << 'EOF'
{
  "schema_version": 1,
  "page_id": "page-01",
  "prompt": "技术封面图，中文标题，白底黑字手绘线条",
  "negative_prompt": "",
  "role": "cover",
  "target_ratio": "16:9"
}
EOF

Step 2：用百炼 CLI 生成原始图

bl image generate --prompt "技术封面图，标题，白底黑字手绘线条"
✅ 实测成功： 百炼的标准版 qwen-image-2.0 画图非常稳，不像 Pro 模型有各种审核问题。

Step 3：Skill 脚本收口

rm -f /tmp/page-01.png /tmp/page-01.manifest.json

python3 ~/.hermes/skills/generating-handdrawn-slide-images/scripts/generate_image.py \
  --request /tmp/page.json \
  --adopt /home/yhy/bailian-output/images/image_xxx.png \
  --output /tmp/page-01.png \
  --accept-ratio-mismatch
难点 5：manifest 冲突。 重复执行会报 refusing to overwrite an existing manifest。必须先 rm -f 清理旧文件。
难点 6：比例不匹配。 bl 默认出正方形，target 是 16:9。用 --accept-ratio-mismatch 接受，或让 bl 指定尺寸。

Step 4：尺寸验证

python3 ~/.hermes/skills/generating-handdrawn-slide-images/scripts/image_delivery.py \
  inspect /tmp/page-01.png --target-ratio 16:9

五、最终可用的「使用手册」

# 1. 设置环境（每次新终端都要做）
export DASHSCOPE_API_KEY="你的Key"
export DASHSCOPE_WORKSPACE_ID="你的ID"
export DASHSCOPE_REGION="beijing"

# 2. 生成原始图
bl image generate --prompt "你的主题，手绘风格" 

# 3. 找到最新文件
ls ~/bailian-output/images/ | tail -1

# 4. 收口（替换 HOST 路径）
rm -f /tmp/page.png /tmp/page.manifest.json
python3 ~/.hermes/skills/generating-handdrawn-slide-images/scripts/generate_image.py \
  --request /tmp/page.json \
  --adopt /home/yhy/bailian-output/images/上一步文件名 \
  --output /tmp/page.png \
  --accept-ratio-mismatch

# 5. 验证
python3 ~/.hermes/skills/generating-handdrawn-slide-images/scripts/image_delivery.py \
  inspect /tmp/page.png --target-ratio 16:9

六、难点速查表

#问题解决
1PEP 668 禁止 pip install--break-system-packages
2缺少三个环境变量export DASHSCOPE_* 三个变量
3Workspace ID 获取困难bailian.console 创建应用
4Pro 模型 API 不兼容改用 bl + --adopt 混合路径
5manifest 重复冲突生成前 rm -f 清理
6比例不匹配--accept-ratio-mismatch

七、总结

这个 Skill 的理论设计很优雅——两条路径自动选择，一条命令出图。但现实是：

  1. Qwen Pro 路径卡在模型兼容性——脚本和 API 之间的版本差导致无法调通
  2. Host-native 路径能跑——虽然多了 bl 这一步中转，但稳定可用
  3. 三个环境变量是关键——每次新终端都要 export，建议写入 ~/.bashrc
一句话总结：脚本的 Qwen 直连路径在 2026 年 7 月的环境下不可用，但 bl + adopt 的混合路径可行。期待脚本升级支持标准版 qwen-image-2.0。
